Two panels.
Every file, at your fingertips.

A modern, keyboard-first file manager in the spirit of Total Commander. Lock your favourite folders into tabs, open zip, 7z and tar archives like folders, work on servers and cloud storage side by side with your disk, preview anything from a song to a spreadsheet, and keep both hands on the keyboard.

Made for moving fast

Everything a power user reaches for

Built with .NET MAUI and Shiny Controls - a native app on all three desktops, from one code base.

New

Folder tabs, your way

Tabs sit on top of each panel like real folder tabs, with a badge counting what you've marked. Right-click one to rename it, give it a colour and an icon.

  • Lock a tab and it stays on its folder - anywhere else opens in a new tab
  • Home, Desktop, Documents, Downloads and cloud folders start as locked tabs
  • Tabs, locks, names and colours come back on the next launch
New

Breadcrumbs that drop down

The path is a breadcrumb trail. Click a crumb to jump there, or its chevron to see the folders inside - and pick one without leaving the keyboard row.

  • The folder you're in is always in view, however deep
  • Prefer typing? The pencil turns it back into a path box
New

Archives that act like folders

Press Enter on an archive and work inside it like any folder: copy in and out, move, rename, delete, make folders - or press F4 to edit a file and save it straight back in.

read & write browse & copy out

  • Pack files or whole folders - everything under them - into any writable format
  • Copy straight from one archive into another
New

Servers and cloud storage, in a panel

Open an SFTP server, a WebDAV share or an S3 bucket and it works like any folder: copy up and down with F5, move, rename, delete, make folders - or press F4 to edit a file and every save goes straight back to the server.

SFTPFTPFTPSWebDAVAmazon S3Azure BlobSMB shares
  • Buckets and containers are folders - make one to create it, delete one to remove it
  • S3-compatible services too: MinIO, Cloudflare R2, Wasabi, Backblaze B2
  • Moves on the same server are instant renames - nothing comes down and goes back up
  • Saved connections sit in the drive bar beside your disks
New

Connect in a keystroke

Press ⌘K - or CtrlK on Windows and Linux - for your saved connections and the file servers announcing themselves on your network.

  • Network shares found by Bonjour mount the way your OS does it, then open like any drive
  • Passwords live in your keychain - macOS Keychain, Windows Credential Manager or the Linux Secret Service - never in a settings file
  • SSH keys, host keys checked on every connect, and a Test button before you save
New

A SQLite workbench behind F4

Press F4 on a .db, .sqlite or .db3 file and get a database editor, not a wall of bytes: tables, views, indexes and triggers down the side, the rows a page at a time.

  • Edit rows in place - click a row to change it, insert with a form, delete with a confirm
  • Design tables: rename, add and drop columns, change types, keys, defaults and foreign keys - SQLite's table rebuild done for you, rows, indexes and triggers kept
  • A live diagram of every table and foreign key - drag from one table to another to add a key, select a line to drop it
  • Run any SQL, edit any CREATE statement, make new tables, views, indexes and triggers
New

Photo metadata, edited losslessly

F4 on a JPEG opens its EXIF: title, description, keywords, author, copyright, date taken, camera and GPS location - with every other tag listed below.

  • Only the metadata is rewritten - the picture stays byte for byte what it was
  • Remove location or strip everything before you share a photo
New

A preview for everything under the cursor

Press CtrlQ and a third pane opens beside (or under) both panels. Move the cursor and it follows - photos, songs, videos, Word documents, spreadsheets, slide decks, PDFs, web pages, Markdown and SQLite tables, even inside archives and on servers.

  • Play audio and video right there - title and artist from the tags, nothing starts until you press play
  • Read Word, Excel and PowerPoint files without opening Office - read-only, so a stray key never changes a thing
  • Web pages render with their scripts off; links open in your browser
  • Dock it right or below, drag it to size, and switch off any previewer you don't want
New

Columns that read what's inside

Walk into a music folder and Duration, Artist, Album and Track appear. A photo folder gets Dimensions, Date taken and Camera; documents get Pages and Author. The columns come from the files themselves, read in the background - only the files on screen, more as you scroll.

  • Sort by any of them - the longest song, the biggest photo, the newest shot
  • Photos, video, music, documents, text and code, archives and apps - pick each set's columns in Settings
  • Lens, aperture, ISO, codecs, bitrate, word counts, line counts and more, one click away
New

Your columns, in your order

One screen for every column beside Name. Add Camera, Duration or Pages to every folder - each one fills in only for the files it applies to - and move any column, built-in or not, to where you want it. The headers and rows follow straight away.

  • Built-in and custom columns, side by side - Size before Camera, Date created at the end, whatever reads best
  • In a remembered folder it edits that folder's columns, with every folder's a click away
  • A narrow panel drops the least useful columns first, so Name stays readable
New

Folders that remember how you like them

Global settings work for almost every folder. For the few that need something else, ⌘⇧V remembers that folder's columns, sort and view - your wallpapers as thumbnails, your music sorted by duration - and leaves everything else alone.

  • Just this folder, or everything below it - the nearest remembered folder wins
  • Change the view there and the setup follows; a badge on the path shows it's in use
  • Every setup listed in Settings, one tap to forget

And so much more

The details that make it yours

Dual panels

Side by side or stacked, with drive chips, a free-space meter, sortable columns and live refresh.

Background jobs

Copy, move, delete, pack and unpack keep running while you work - uploads and downloads too - with progress, Stop and Go To.

Find files

Total Commander masks like *.cs | bin/, content search, size filters and go-to-file.

Multi-rename

Placeholders, counters, regex search & replace and a live preview - with undo, even inside archives.

Synchronize folders

Compare trees by date, size or content and copy what's different, in either direction.

Command line

Type anywhere: cd moves the panel, anything else runs in your shell with output in a console.

Rename in place

F2 edits the name right on its row or tile, the extension left out of the selection. Enter keeps it, Esc backs out - and a tab renames the same way.

A ribbon that shows what's on

Folder Tree, Hidden Files, Thumbnails, Preview and the rest stay pressed while they're on - for the panel you're in.

An editor for each kind of file

F4 picks the editor that understands the file - SQLite databases, photo metadata, Markdown with a live preview, text for the rest - or hands it to your favourite editor.

Folder sizes

AltShiftEnter or the ribbon sizes the marked folders, the one under the cursor, or every folder at once.

The right app, every time

Double-click or Enter opens a file in its own app - Word files in Word, spreadsheets in Excel - and asks which app when nothing claims it. ⌘PgDn still looks inside a .docx like an archive.

Cloud-only files

Files iCloud Drive, OneDrive or Dropbox keep only in the cloud wear a cloud, so you know before you open one.

Your keys stay yours

Server passwords and storage keys go to the OS keychain. Forget one any time from its connection.

Finds your network

NAS boxes, Macs and servers that announce themselves show up ready to connect - SMB, SFTP, WebDAV and FTP.

Edit anywhere

F4 on a file in an archive or on a server edits a copy - and every save is written back where it came from.

Light & dark

Follows your system, or pick a theme. Every icon and colour is tuned for both.

Speaks your language

English, French and Spanish, following your system or chosen in Settings.

Under the hood

The tech stack

C# and .NET 10 from top to bottom. One shared .NET MAUI interface runs natively on WinUI, AppKit and GTK4 - no web view, no Electron.

Language & runtime

  • .NET 10the runtime, on all three desktops
  • C#every line of the app
  • XAMLthe pages and controls

UI & platforms

  • .NET MAUIthe shared UI
  • maui-labsnative AppKit on macOS, GTK4 on Linux
  • Shiny Controlsribbon, data grids, keyboard shortcuts, dialogs, Markdown, diagrams, the media player and the Word, Excel and PowerPoint viewers

App architecture

  • Shiny MAUI ShellViewModel-first navigation
  • Shiny Mediatorevents between pages
  • Shiny ExtensionsDI, persisted settings, typed localization
  • CommunityToolkit.Mvvmview models

Files & formats

  • SharpCompress7z, rar and compressed tars
  • System.IO.Compression · System.Formats.Tarzip and tar
  • ExifLibNetlossless EXIF edits
  • TagLibSharpdurations, dimensions and tags for the columns
  • Microsoft.Data.Sqlitethe SQLite editor

Servers & cloud

  • SSH.NETSFTP
  • FluentFTPFTP and FTPS
  • AWS SDK for .NETS3 and S3-compatible storage
  • Azure SDK for .NETAzure Blob storage
  • Shiny.Net.Discoveryservers on your network

Testing

  • xUnit v3tests
  • Shouldlyassertions
  • MAUI DevFlowUI tests that drive the real app
